# Spaces, values and Tensor

Part of the [language parity spec](../language-parity.md). Status: Draft —
reviewed round 6. Draft: C# column pending review. [Rules](rules.md) apply throughout; paths use its
abbreviations (`py/`, `pyrs/`, `rs/`, `capi/`, `h`, `hpp`).

Scope: `rlmesh.spaces` (`Space`, `Box`, `Discrete`, `Dict`, `SpaceSpec`,
`space_from_spec`), `rlmesh.specs.SpaceSpec` (the same class), the values that
`sample()` returns and `contains()` accepts, `rlmesh.Tensor`, the C text view,
and what `RANDOM_SAMPLE` does when it samples. Running owns the
`RANDOM_SAMPLE` symbol, Core owns `Value`, Env owns `EnvContract` (R-27).

## Shape

```python
from rlmesh import Tensor
from rlmesh.spaces import Box, Dict, Discrete

obs = Dict({"pos": Box(-1.0, 1.0, [3]), "id": Discrete(4, start=1)})
obs.seed(7)
x = obs.sample()                       # {"id": int, "pos": Tensor}: keys sorted at construction (SPC-11)
assert obs.contains(x) and obs["pos"].low == -1.0
t = Tensor(b"\0" * 24, [2, 3], "float32")
```

```rust
use rlmesh::spaces::{Box, BoxOptions, Dict, Discrete, DiscreteOptions, SpaceSpec};
use rlmesh::{DType, Tensor};

let pos = Box::new(-1.0, 1.0, [3], BoxOptions::default())?;
let id = Discrete::new(4, DiscreteOptions { start: 1, ..Default::default() })?;
let obs = Dict::new([("pos", SpaceSpec::from(&pos)), ("id", SpaceSpec::from(&id))])?;
obs.seed(Some(7));
let x = obs.sample()?;
assert!(obs.contains(&x));
let t = Tensor::new(&[0u8; 24], &[2, 3], DType::Float32)?;
```

```csharp
using RLMesh;
using RLMesh.Spaces;

var obs = new Dict(new Dictionary<string, SpaceSpec>
{
    ["pos"] = new Box(-1.0, 1.0, new long[] { 3 }),
    ["id"] = new Discrete(4, new DiscreteOptions { Start = 1 }),
});
obs.Seed(7);
Value x = obs.Sample();
Debug.Assert(obs.Contains(x) && obs["pos"].AsBox()!.Low is BoxBound.Uniform { Value: var low } && low.AsFloat() == -1.0);

```

C `RLMeshBox`, `RLMeshDiscrete` and `RLMeshDict` are typedefs of
`RLMeshSpace` (SPC-1), so a Dict passes to `rlmesh_space_*` without a cast
and is cloned and freed with `rlmesh_space_clone` / `rlmesh_space_free`.

## Parity table

Errors follow R-21: invalid values raise the `ValueError` class, including a
spec of another kind passed to `from_spec` / `Box(spec)` (SPC-P2); a typed
accessor called on a handle of another kind raises the `TypeError` class.
"—" means no counterpart (cited rule).

C#: `Bound`'s implicit conversions mirror Rust's `From` set (SPC-35), so
`new Box(0, 5, new long[] { 2 }, new BoxOptions { Dtype = DType.Int32 })`
picks `int` → Int exactly and `new Box(-1.0, 1.0, …)` picks Float; `nint` /
`nuint` and `char` have none (R-5). C's `RLMeshBound` (an enum tag plus a
union) is passed by value through the raw layer as a generated
explicit-layout struct; `Bound` is the public form and never exposes the
union.
